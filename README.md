# Krypton IELTS Studio

A lightweight, responsive IELTS practice dashboard for Listening, Reading, Writing, and Speaking. It runs as a static website with no build step.

## Run it

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Included

- Short Listening transcript and Reading comprehension drills with answer feedback
- Writing prompt with a word counter and locally saved draft
- Speaking cue card with a preparation timer and notes
- Browser-local session, minute, streak, and weekly activity tracking
- Responsive layout for mobile and desktop

Progress and drafts are stored in the browser's local storage on the device where you practise. The sample exercises are original practice material and are not official IELTS test questions.
